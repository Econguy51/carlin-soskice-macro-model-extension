MATLAB Supplementary Code for "Teaching Macroeconomic Dynamics: Analyzing the Carlin-Soskice Three-Equation Macro Model Using MATLAB and the Routh-Hurwitz Criterion"
Author: Christopher R. Herdelin

FILES INCLUDED:
1. reduced_form_equation.m - 2D dynamic simulation & phase space portrait/nullclines.
2. structural_equation_3x3.m - 3D structural model simulation & stability test.
3. parameter_sweep.m - Numerical grid search map of system stability boundaries.

INSTRUCTIONS:
Open the desired .m script file in MATLAB and run to generate numerical outputs and figures.
